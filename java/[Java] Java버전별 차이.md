# 자바 1.8과 8 차이
공식적인 이름은 Java SE 8이고 
개발자들을 위한 버전명은 1.8이다.

자바는 언어이자 플랫폼이다.
개발자는 .java 확장자를 가진 파일에 소스코드를 작성한다.
자바 컴파일러(javac)가 .class 파일로 컴파일 한다.
*컴파일러 : 특정 프로그래밍 언어로 쓰여있는 문서를 다른 언어로 옮기는 프로그램. 원시 코드에서 목적 코드로 옮기는 과정을 컴파일이라고 함.
.class 파일은 bytecode로 되어 있고 jvm은 자신이 구동되고 있는 os를 인식한 후 bytecode를 해당 프로세서에 맞는 native machine code로 변환.
자바는 이와 같은 과정을 통해 os에 독립적으로 사용할 수 있기에 플랫폼이라고도 할 수 있다.

# 자바 8, 11, 17 버전 차이
LTS는 Long Term Support로 오랜 기간 지원하는 특별한 버전의 에디션. 대부분 LTS 버전을 사용.
자바 8  = 1.8

8 -> 11 -> 17 순서로 나옴.
8 버전은 이전 버전과 확연한 차이가 있고 2030년 까지 가장 오랜 기간을 지원하는 버전임.
우리 회사에서 8 이전 버전을 사용하는 프로젝트들은 최소 1.8로 버전업이 필요.
경우에 따라 17 버전으로도 업그레이드 필요.
