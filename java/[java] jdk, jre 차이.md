# JRE(Java Runtime Environment)
자바 실행환경. 
자바 프로그램을 실행할 때 필요한 것.
자바 프로그램을 코딩할 때 jdk가 아니라 jre를 사용하면 컴파일이 정상적으로 되지 않을 수 잇다.

# JDK(Java Development Kit)
자바 개발 키트.
자바를 개발하는데 필요한 기능이 들어가있다.
자바를 실행하는데 필요한 JRE도 포함되어 있다.
자바 프로그램 개발을 위해서는 jdk를 다운받아 자바를 사용하고 컴파일해야 한다. 

정리하면 자바 프로그램을 실행할때 필요한건 jre이며
자바 프로그램을 개발할 때 필요한건 jdk이다. jdk에는 jre가 포함되어 있다.
