# Azure 글로벌 인프라 용어와 개념
지리(Geography) > 지역 쌍(Region Pair) > 지역(Region) > 영역(Zone) > 데이터센터

## 데이터 센터
- 독립적인 전원 및 냉각장치, 네트워크를 갖춘 별도의 시설
- 한국 중부와 남부에 위치한 데이터 센터는 마이크로소프트가 LG U+, KT의 데이터센터를 임차해 사용 중이다. 
- 부산에 새로운 데이터 센터를 구축했다.

## 영역(Zone)
- 하나 이상의 데이터 센터를 가진 지역 내의 물리적 별도 위치를 가용성 영역(Availability Zone)이라고 함.
- 데이터 센터의 오류나 손상에 대비해 서비스의 논리적 격리와 중복성, 내결함성을 제공
- 한 지역에는 3개 이상의 가용성 영역이 있을 수 있고 각 영역 간의 대기 시간은 2ms이하를 보장
- 고가용성 및 탄력적인 서비스로 복원력과 유연성 제공, 지역 재해로부터 비즈니스 연속성 및 재해복구를 제공

## 지역(Region)
- 최상의 성능과 보안을 제공하기 위해 고속 네트워크로 연결된 데이터 센터 집합 
- 일정한 대기 시간(< 2ms)을 정의하는 경계
- 한국은 현재 중부와 남부 2개 지역을 제공

## 지역 쌍(Region Pair)
- 일반적으로 동일한 지리적 위치 내에 있는 2개의 지역을 말함
- 예외도 있음.
- 한국은 2017년에 오픈한 중부 지역을 시작으로 이후 추가된 남붑 지역과 지역 쌍을 이루며 리전 간 재해복구 옵션 제공.

## 지리(Geography)
- 2개 이상의 지역을 포함하며 데이터와 애플리케이션을 동일한 지리적 위치에 유지해야 하는 데이터 유지 및 규정 준수 경계를 말함
- 전용 고속 네트워크 인프라를 갖추며 지역에서 발생하는 장애에 내결함성을 제공
- 주로 나라별로 구분되지만, 더 큰 범주의 지리적 위치도 포함(아시아 태평양, 아프리카 등)



# 리소스와 리소스 그룹
- 구독 > 리소스 그룹 > 리소스
- 리소스는 하나의 리소스 그룹에만 존재해야 한다.
- 리소스와 리소스 그룹 이름은 변경할 수 없다.
- 동일한 구독 내에서 리소스 그룹 이름은 고유해야 한다.
- 리소스 그룹과 리소스의 위치가 다를 수 있다.
- 리소스를 다른 리소스 그룹으로 이동할 수 있다.


리소스 그룹의 위치는 리소스의 메타 데이터가 저장되는 위치이다.
데이터 존재 위치에 대한 규정 준수 문제가 있다면 위치가 중요함.
