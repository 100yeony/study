# cmd
- 초창기 Window 운영체제부터 사용되던 명령 프롬프트
- 모든 Windows 운영체제에서 사용 가능
- 간단한 기본 명령어 실행(cd, ls, m idkr, rm 등)
- window 기반 운영체제를 위한 명령줄 및 스크립팅 언어

# powershell
- 기능이 많이 추가된 고급 버전 CMD
- Windows 2007 버전 이후로부터 사용 가능
- CMD + 고급 기능(변수 선언, 함수 만들기 등)
- Windows 2007 이상 운영체제를 위한 명령줄 및 스크립팅 언어

# bash
- Linux, Unix에서 사용되는 기본 shell
- 초창기부터 Linux, Unix 시스템에서 사용되었음.

따라서 Powershell과 Bash는 서로 다른 운영체제에서 사용되기 때문에 비교 대상이 아니다.
