프로그래밍 언어는 보통 정적 타입 언어, 동적 타입 언어로 나뉜다.

# 타입이란?
    프로그래밍 언어에서 타입은 자료형을 의미한다.
    int형, short형, float형, bool형, 객체 등 
    타입은 변수가 어떤 값을 가질 수 있는지, 어떤 연산을 할 수 있는지를 제한한다.
    변수 선언 시 항상 앞에 붙인다.

# 정적 타입 언어(Statically typed language)
    정적 타입 언어는 컴파일 시 변수 타입이 결정되는 언어다.
    작성자가 변수 타입을 직접 작성하는 언어.
    C, C#, C++, Java 등이 있다.
    컴파일 시 자료형에 맞지 않은 값이 들어 있으면 컴파일 에러가 발생한다.

    장점
        - 타입 에러로 인한 문제를 초기에 발견할 수 있어 타입 안정성이 높다
        - 컴파일 시 미리 타입을 결정하기 때문에 실행 속도가 빠름
        - 코드 가독성이 좋아 유지보수에 유리
    단점
        - 코드 작성 시 매번 타입을 결정하는게 번거로움

# 동적 타입 언어(Dynamically typed language)
    런타임 시 변수 타입이 결정되는 언어.
    코드를 실행할 때 알아서 변수 타입을 판단해주는 언어.
    JavaScript, Python, Ruby 등
    컴파일 시 자료형을 정하는게 아니라 런타임에서 결정됨

    장점
        - 코드 실행 시 자동으로 변수 타입을 판단하여 지정
        - 작성자가 타입을 매번 지정할 필요가 없어서 빠르게 코드 작성 가능
    단점
        - 실행 도중 변수에 예상치 못한 자료형이 들어오면 타입 에러가 발생
        - 타입 관련 에러를 런타임 시 확인 가능하기 때문에 코드가 길고 복잡해질 경우 타입 에러 찾기가 어려워짐.
